# delta

Rust port of [pi](https://github.com/earendil-works/pi)'s libraries.

| Crate | Import | Upstream | What it does |
| --- | --- | --- | --- |
| [`delta-ai`](crates/ai) | `delta_ai` | `@earendil-works/pi-ai` | Unified LLM API: provider collections, auth resolution, streaming events, token and cost tracking, tool calling, cross-provider context hand-off |
| [`delta-agent`](crates/agent) | `delta_agent` | `@earendil-works/pi-agent-core` | Stateful agent: tool execution (parallel or sequential), steering and follow-up queues, lifecycle events and hooks |

Status: in development; nothing is published yet.
